# Generation Language — [Brand Name]

Promptable, principle-level language for briefing a designer,
image-generation model, or another agent on any new asset. Each entry is a
reusable rule, not a one-off scene description — it should produce
on-direction output across unrelated prompts, not one memorable result
once.

## How to use this file
For any new asset request, apply the relevant principles below rather than
writing a fresh scene description from scratch. If a new asset type
reveals a gap this file doesn't cover, extend this file — don't invent a
one-off exception that lives only in that asset.
