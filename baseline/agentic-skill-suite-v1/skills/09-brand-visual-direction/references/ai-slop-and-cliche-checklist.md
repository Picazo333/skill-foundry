# AI-Slop and Category-Cliché Checklist

Used in `SKILL.md` step 4. A territory that matches 2+ items below with no
explicit strategic override recorded fails the cliché flag.

## Generic AI-generated-aesthetic defaults (cross-category)
- Purple-to-blue (or pink-to-orange) gradient mesh as a default background,
  used because it reads as "modern/tech" rather than because the strategy
  demands it.
- Glassmorphism (frosted translucent panels) applied by default rather
  than as a deliberate materiality choice tied to a strategic tension.
- Abstract blob shapes / organic gradient blobs used as filler
  decoration with no compositional or informational role.
- Generic line-art or flat-illustration human figures with no
  distinguishing features, interchangeable across any brand.
- Indiscriminate rounded-corner (2xl+) cards with soft drop-shadow on
  every element regardless of hierarchy or content type.
- Stock "diverse hands collaborating on a laptop" or "team high-fiving in
  a bright open office" photography.
- Oversized, glossy 3D-rendered orbs/spheres/abstract objects floating in
  a gradient void, used as a generic "innovation" signal.
- Overuse of a single trendy display typeface (currently: heavy geometric
  sans with exaggerated letterforms) as a default "distinctive" choice
  that has become its own new cliché through overuse.
- Emoji or emoji-style icons used as a substitute for a considered icon
  system.

## Category defaults (examples — extend per the actual category in scope)
- **Finance / fintech:** navy + white + a single "trust" accent (usually
  green or blue); serif or geometric sans logotype; up-and-to-the-right
  line chart as default hero graphic; handshake or growth-arrow iconography.
- **Health / wellness:** sage green or pastel palette; hand-lettered or
  soft rounded type; leaf/plant iconography; soft-focus lifestyle
  photography of relaxed people.
- **AI / dev tools:** dark mode by default with a single neon accent
  (cyan or violet); monospace type as a default "technical" signal;
  particle/network-node graphics as a default "AI" visual shorthand.
- **Consumer apparel / DTC:** oversized serif wordmark; muted earth-tone
  palette; grainy film-photo texture applied uniformly regardless of
  product category.
- **Dental / medical-adjacent:** clinical white + single accent (often
  teal or mint); tooth or smile iconography; overly literal "clean/bright"
  visual signaling that reads as generic rather than differentiated.

## How to use this list
1. For each territory, check its 8-axis definition against every item
   above.
2. Count matches. 0–1 matches with no strategic tie: proceed.
3. 2+ matches: either (a) argue explicitly why the strategy demands this
   specific category default despite the risk (e.g. a strategy whose
   differentiation is deliberately *not* visual — record this as an
   explicit override with rationale), or (b) rebuild the flagged axis per
   the divergence-audit rebuild rule in
   `references/territory-generation-framework.md`.
4. Never silently drop a flagged territory without recording the flag —
   the flag itself is evidence for `VISUAL_ANTI_PATTERNS.md`.
