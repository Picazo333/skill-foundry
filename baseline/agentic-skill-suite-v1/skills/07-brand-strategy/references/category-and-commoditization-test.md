# Reference: category framing and the commoditization stress test

Used in `SKILL.md` step 4 (category/competitive frame) and step 9
(contradiction/commoditization test).

## Framing the category

1. **Direct competitors** — brands the audience actively compares this one
   against when deciding.
2. **Indirect/substitute alternatives** — different category, same job the
   audience is hiring the product/service to do (including switching costs
   of staying with an incumbent solution).
3. **"Do nothing"** — always list this. Many categories underestimate that
   their real competitor is the audience's status quo inertia.
4. **Dominant conventions** — the visual/verbal/positioning clichés nearly
   every player in the category currently uses (e.g. "trusted", "innovative",
   "personalized" with no specific proof attached). A distinctive position
   either deliberately breaks one of these or deliberately, visibly
   conforms to one for a stated strategic reason (never by default/inertia).

If no competitor map is supplied, build this frame directly from whatever
competitive mentions exist in the discovery brief, and mark it explicitly as
a minimal frame in `BRAND_STRATEGY.md`'s unresolved section — do not present
a thin, inferred frame as if it were researched.

## The commoditization swap test

Run this on the recommended territory before finalizing it (`SKILL.md` step
9), and on any territory scoring evenly-mediocre across all five axes in
`references/positioning-territory-scoring.md`.

1. Write the positioning statement in the form: "<Brand> is the
   <category> that <claim>, because <RTB>."
2. Substitute the name of the strongest direct competitor for `<Brand>`.
3. Ask: does the sentence still read as true, or at least plausible, for
   that competitor?
   - **If yes** — the position is commoditized. It is not tied to anything
     specific to this brand. Fail the test; return to territory generation
     (step 5/6) rather than shipping it.
   - **If no** — because the RTB is something only this brand can credibly
     claim, or the claim would visibly contradict what's known about the
     competitor — the position passes.

## Common commoditization traps

- Adjectives with no attached proof ("innovative", "customer-first",
  "premium quality") — nearly every competitor in nearly every category
  already claims these; they fail the swap test by default.
- A positioning built entirely on category table-stakes (e.g. "safe",
  "reliable" in categories where that's the baseline expectation, not a
  differentiator) — table-stakes belong in guardrails/proof requirements,
  not in the differentiation statement.
- A claim that is true of the category, not the brand (e.g. "personalized"
  in a category where every competitor already personalizes).
