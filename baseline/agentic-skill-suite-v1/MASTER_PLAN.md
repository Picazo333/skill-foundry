# MASTER PLAN — 15-SKILL AGENTIC SUITE

## Strategic thesis

This suite encodes repeated workflows into reusable capabilities instead of rebuilding narrow Custom GPTs.

### Cross-functional workflows repeatedly used
- reconstruct fragmented project context;
- architect exhaustive research before execution;
- audit apps/products and create agent-ready plans;
- turn chaotic dictation into structured operational updates;
- route work to the best AI given capability, quota and reset pressure.

### Brand workflows repeatedly used
- discovery;
- positioning/strategy;
- verbal identity;
- visual direction;
- identity systems;
- brand books;
- creative briefs;
- content systems;
- quality control;
- workflow orchestration.

## Design philosophy
- Deep capabilities > many micro-prompts.
- Canonical artifacts > conversational memory.
- Orchestration > manual continuation loops.
- QA/evals are first-class.
- Skills reduce repeated cognitive work.
- Every skill should be usable by a human or another agent.
- Cross-platform portability comes from canonical core + thin adapters.

## Acceptance target
A completed skill should behave like a bounded agent:
- clear job;
- clear state;
- explicit I/O;
- predictable procedure;
- bounded autonomy;
- quality gate;
- recovery path;
- downstream handoff.

See `skills/*/SPEC.md` for exact contracts.
