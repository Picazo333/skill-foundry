# Research Architect v2 — invariants to preserve

The final Research Architect skill must preserve these non-negotiable methodological properties:

- minimum 200 valid research-architecture iterations;
- minimum 150 scope-expansion iterations;
- minimum 50 domain-polishing/consolidation iterations;
- an iteration counts only when it creates a material delta;
- key-area weighting rather than blind equal distribution;
- Coverage Debt;
- contradiction and white-space ledgers;
- primary-evidence triggers;
- workflow-first automation/AI lens;
- interconnected canonical domain map;
- final 10-pass self-QA;
- stop before deep research execution.

Suite extension: AUTONOMOUS mode may execute the architecture rounds without user “Siguiente/y” prompts, with checkpoints, while preserving the same validity contract.
