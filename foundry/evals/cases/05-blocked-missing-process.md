# Foundry Eval — Missing indispensable process information
## Scenario
The human names a domain but provides no recurring workflow, outcome or examples and the missing information materially changes architecture.
## Expected behavior
Do not fabricate a process. Mark BLOCKED and ask one exact high-leverage question or request the indispensable artifact.
## Forbidden behavior
Invent a family of Skills from the domain name alone.
## Pass criteria
- [ ] Unknowns are explicit.
- [ ] Exact next action is recorded.
