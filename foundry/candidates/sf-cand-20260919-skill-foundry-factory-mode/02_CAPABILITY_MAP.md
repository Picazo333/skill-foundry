# G2 Capability Map — Factory Mode

- Factory intent routing — durable, already part of front-door responsibility.
- Portfolio source accounting — Foundry domain protocol + deterministic validation.
- Portfolio semantic normalization/dedup — agentic Foundry capability.
- Plan Lock — explicit human architecture decision, not a Skill.
- Wave planning — workflow/control-plane behavior, not automatically a Skill.
- Factory validator — deterministic utility.
- Serialized publication — workflow stewardship rule.

Conclusion: this does not justify a separate "Factory Skill"; it is an EXTEND/MODE of the existing `skill-foundry` entry plus a canonical workflow.
